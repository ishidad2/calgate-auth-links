Privacy Policy

In the event of any discrepancy between the Japanese and English versions of this policy, the Japanese version shall prevail. The Japanese version is available at https://auth.daisan.dev/privacy.

CalGate (the "App") is developed and provided by Daizo Ishidad2 (the "Developer"). This policy describes the information the App collects and how it is used.

1. Overview

CalGate is a tool for managing multiple Google Calendar accounts and preventing scheduling conflicts. The Developer respects user privacy and uses only the minimum necessary information. The App has no backend server. All data is stored exclusively on the user's device.

2. Information We Collect

The App collects and stores the following information:

  • Google Account information: Email address, display name
  • OAuth access tokens / refresh tokens: Authentication credentials required to access the Google Calendar API
  • Calendar event information: Event title, start time, end time
  • Purchase status: A flag indicating whether the Workspace feature unlock has been purchased (not encrypted)
  • App settings: Custom account labels, theme colors, default event durations, etc.

The App does not collect advertising IDs, location data, contacts, photos, microphone data, or similar information.

3. How We Use Your Information

  • Google Account information: Used to identify multiple accounts and write to the Google Calendar API
  • Calendar event information: Used solely to create blocking events (out-of-office blocks) on other accounts
  • Purchase status: Used to determine whether the Workspace feature is available
  • App settings: Used to retain user-configured customizations

4. Data Storage and Security

All information is stored only on the user's device. No data is transmitted to external servers.

  • OAuth tokens: Stored encrypted in the device Keychain (iOS) / Keystore (Android) using flutter_secure_storage
  • Purchase status and app settings: Stored in the device's local storage using shared_preferences. This storage area is not encrypted.

5. Sharing with Third Parties

The Developer does not sell or rent user personal information to third parties. Data is shared only with the following services:

  • Google LLC: For Google Calendar API access and OAuth 2.0 authentication. Google Privacy Policy
  • Apple Inc.: For in-app purchase processing on the App Store (iOS). Apple Privacy Policy
  • Google LLC (Google Play): For in-app purchase processing on Google Play (Android).

6. Cross-Account Data Use

As a core feature of the App, event information (title, date/time) entered in one account (e.g., personal account A) is used to automatically create a blocking event on another account (e.g., work account B). This data is processed only on the device and is never sent to external servers.

When Privacy Mode is enabled, only "Out of Office" is sent to other accounts. No event title, location, or description is transmitted.

7. Data Retention and Deletion

  • When signing out of an account: The OAuth tokens and settings for that account are deleted from the device
  • When uninstalling the App: On iOS, all data except Keychain data is deleted. On Android, all data is deleted

Users can delete any account at any time from the Account Settings screen within the App.

8. Children's Privacy

The App is not directed at children under the age of 13. The Developer does not knowingly collect personal information from children under 13. If we become aware that personal information from a child under 13 has been collected, we will promptly delete it.

9. Compliance with Applicable Law

The App is operated in compliance with the Act on the Protection of Personal Information (APPI) of Japan and other applicable privacy laws. For requests regarding access, correction, or deletion of personal information, please contact us using the details below.

10. Changes to This Policy
