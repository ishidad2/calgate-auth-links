プライバシーポリシー

CalGate（以下「本アプリ」）は、ishidad2（以下「開発者」）が開発・提供するモバイルアプリです。本ポリシーは、本アプリが収集・利用する情報について説明します。

1. はじめに / 基本方針

本アプリは、複数の Google Calendar アカウントを管理し、重複予定を防ぐためのツールです。開発者はユーザーのプライバシーを尊重し、必要最小限の情報のみを使用します。本アプリはサーバーを持たず、すべてのデータはユーザーの端末内のみに保存されます。

2. 収集する情報

本アプリが収集・保存する情報は以下のとおりです。

  • Google アカウント情報：メールアドレス、表示名
  • OAuth アクセストークン / リフレッシュトークン：Google Calendar API へのアクセスに必要な認証情報
  • カレンダーイベント情報：予定のタイトル、開始日時、終了日時
  • 購入状態：ワークスペース機能アンロックの購入済み / 未購入フラグ（暗号化なし）
  • アプリ設定：アカウントのカスタムラベル、テーマカラー、デフォルト予定時間など

広告 ID、位置情報、連絡先、写真、マイクなどの情報は収集しません。

3. 情報の利用目的

  • Google アカウント情報：複数アカウントの識別と Google Calendar API への書き込みに使用します
  • カレンダーイベント情報：他のアカウントへのブロック予定（不在ブロック）作成のみに使用します
  • 購入状態：ワークスペース機能の利用可否判定に使用します
  • アプリ設定：ユーザーが設定したカスタマイズ内容の保持に使用します

4. 情報の保存・管理

すべての情報はユーザーの端末内にのみ保存されます。外部サーバーへの送信は行いません。

  • OAuth トークン：端末の Keychain（iOS）/ Keystore（Android）に暗号化して保存されます（flutter_secure_storage を使用）
  • 購入状態・アプリ設定：端末のローカルストレージに保存されます（shared_preferences を使用）。この領域は暗号化されていません。

5. 第三者への情報提供

開発者はユーザーの個人情報を第三者に販売・賃貸しません。以下のサービスとのみデータをやりとりします。

  • Google LLC：Google Calendar API および OAuth 2.0 認証のため。Google プライバシーポリシー
  • Apple Inc.：App Store でのアプリ内課金処理のため（iOS）。Apple プライバシーポリシー
  • Google LLC（Google Play）：Google Play でのアプリ内課金処理のため（Android）。

6. アカウント間のデータ利用

本アプリの中核機能として、あるアカウント（例：個人アカウント A）に入力した予定の情報（タイトル、日時）を使用して、他のアカウント（例：会社アカウント B）にブロック予定を自動作成します。このデータは端末内でのみ処理され、外部サーバーには送信されません。

プライバシーモードが有効な場合、他アカウントへは「不在」のみが送信され、予定タイトル・場所・説明は一切送信されません。

7. データの保持期間と削除

  • アカウントのサインアウト時：そのアカウントの OAuth トークンおよび設定情報が端末から削除されます
  • アプリのアンインストール時：iOS では Keychain データを除くすべてのデータが削除されます。Android ではすべてのデータが削除されます

ユーザーはアプリ内のアカウント設定画面から、いつでも各アカウントを削除できます。

8. お子様のプライバシー

本アプリは 13 歳未満のお子様を対象としていません。13 歳未満のお子様から意図的に個人情報を収集することはありません。万一 13 歳未満のお子様の情報が収集されていることが判明した場合は、速やかに削除します。

9. 個人情報保護法（APPI）への対応

本アプリは、日本の個人情報の保護に関する法律（個人情報保護法）に基づき、ユーザーの個人情報を適切に管理します。個人情報に関するお問い合わせ、開示・訂正・削除のご要望は、下記のお問い合わせ先までご連絡ください。

10. プライバシーポリシーの変更

本ポリシーは予告なく変更される場合があります。重要な変更があった場合は、アプリ内通知またはアプリストアのアップデートノートでお知らせします。変更後のポリシーは本ページに掲載した時点で効力を生じます。
